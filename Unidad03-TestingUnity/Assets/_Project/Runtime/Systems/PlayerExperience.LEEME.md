# PlayerExperience — se construye en clase (Actividad S)

Esta clase **todavía no existe**. Es intencional.

Según la Actividad S de `05-actividad-practica-y-evaluacion.md`, `PlayerExperience.cs`
se construye en vivo siguiendo el ciclo TDD:

1. **RED** — escribir primero el test `GainExperience_IncreasesTotalExperience`
   en `Assets/_Project/Tests/EditMode/` (ver ejemplo de test en
   `docs/unidad03/02-caso-practico-testing-videojuego.md`, Sección H).
   Ejecutarlo y confirmar que falla o no compila.
2. **GREEN** — crear `PlayerExperience.cs` en esta carpeta con lo mínimo
   necesario para que ese test pase. Nada más.
3. **REFACTOR** — mejorar el código sin cambiar el comportamiento. Volver a
   ejecutar el test.
4. Repetir el ciclo completo con el segundo requisito (subir de nivel a los
   100 XP).

No copiar una solución ya resuelta acá: la actividad es justamente escribir
el código a partir del test, no al revés.
