# Clases en vivo — Programación de videojuegos (Windows)

Guía para armar un setup de transmisión en vivo tipo "webcam en esquina + pantalla compartida + zoom/anotaciones en vivo", pensado para dar clases de programación de videojuegos (Unity, VS Code, etc.) desde Windows.

Referencia visual del formato buscado: presentador en un recuadro inferior izquierdo, pantalla completa con la diapositiva/código, transmitido en vivo por YouTube (ej. formato usado por Daxus Latam en sus clases "Inmersión en IA").

## Contenido de esta carpeta

- [01-herramientas.md](01-herramientas.md) — lista de herramientas, para qué sirve cada una, y enlaces de descarga.
- [02-configuracion-obs.md](02-configuracion-obs.md) — pasos detallados para configurar OBS Studio (escenas, fuentes, webcam, audio, streaming a YouTube).
- [03-zoom-anotaciones.md](03-zoom-anotaciones.md) — cómo hacer zoom y dibujar en vivo sobre diapositivas/código con ZoomIt y alternativas.
- [04-bloqueos-y-soluciones.md](04-bloqueos-y-soluciones.md) — problemas comunes (permisos de Windows, drivers de cámara/audio, firewall, rendimiento, restricciones corporativas/antivirus) y cómo resolverlos.
- [05-alternativas.md](05-alternativas.md) — opciones alternativas a OBS/ZoomIt en caso de que alguna herramienta esté bloqueada o no sea viable.
- [06-checklist-clase.md](06-checklist-clase.md) — checklist rápido para antes/durante/después de cada clase en vivo.
- [sesion-2026-08-12.md](sesion-2026-08-12.md) — transcripción del pedido original y contexto de esta sesión.

## Resumen ejecutivo

Herramienta principal: **OBS Studio** (gratis, open source) para capturar pantalla + webcam + audio y transmitir a YouTube.
Herramienta para zoom/anotaciones en vivo: **ZoomIt** (gratis, Microsoft Sysinternals), funciona sobre cualquier programa (PowerPoint, VS Code, Unity Editor).

Con esas dos herramientas se cubre el 100% de lo mostrado en la imagen de referencia. El resto de los documentos amplían configuración, alternativas y solución de problemas.
